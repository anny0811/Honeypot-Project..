# Honeypot Project 
## Overview 
this project is based in the OWASP honeypot and is created to understand the fundamentals of honeypots and threat monitering.
It focuses on leaning how malicious activities can be detected, logged, and analyzed using security tools.

## What is a Honeypot?
A honeypot is a security system designed to simulate vulnerable services in order to attract attackers and study their behavior.
It helps in identiflying attack patterns and improving defenses.

## Project Goals 
- Learn the basics of honeypot-based security
- Understand how attacks are logged and monitored
- Explore the use of Modsecurity with logging tools
- Gain hands-on experience with open-source projects

## Technologies & Tools 
- MosSecurity
- Docker
- ELK Stack (Elasticsearcg, Logstash, Kibana)
- MISP (optional)

## Usage 
This repository is intended for leaning and educational purposes. It helps beginnners explore how security monitoring systems work in a controlled environment.
